# App Store screenshots

`iphone-6.5/` holds six 1284 x 2778 PNGs (RGB, no alpha) for App Store
Connect's iPhone 6.5" slot. Each is a real screen of the Personal build,
rendered from the app at 3x and framed with a one-line caption in the house
fonts (Fraunces, Inter) on Nightshore. Made 2026-10-02.

Rules they follow: no price, no "Plus", no "beta", no other mobile platform
named (guideline 2.3.10, which is why Pairing, with its Tailscale download
list, is left out), and every caption is true of the build.
