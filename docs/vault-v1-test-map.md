# Vault v1: every must-fix finding mapped to a test (plan 8.3, 2026-09-27)

Ship gate 1 in `docs/vault-v1-plan.md` ("no silent loss") is pinned by this
map. Each row is one finding from `docs/vault-v1-review-findings.md` whose
fields say **v1 must** (the review's own tier: every finding carries "v1 must",
"v1 should", or "v1 later"; severity is a separate field, so the must tier
includes some medium and low findings, and every critical and high finding
is in it). That is
101 of the 168 findings. The Plan column names the plan item that closes the
finding; the Test column names the file and the test (a `describe` is named
as such, and a quoted pgTAP line is the assertion's description).

Status:

- **covered**: a test on `main` fails if the defect returns.
- **covered-on-held-branch**: the fix and its test live on a held branch
  (`vault-m2-team`, `vault-m2-icloud`, `vault-m2-native`) and land with it;
  `main` covers only the part named in the row.
- **device-only**: no unit test can hold it; it is a line in
  `docs/vault-v1-device-checklist.md` (plan 8.1).
- **MISSING**: no test holds it yet; listed at the end for a code pass.

Counts: 101 must-fix; 97 covered; 2 covered on a held branch (orgvault-4,
orgvault-7); 2 device-only (truth-22, truth-23); none missing.

Notes on the reading:

- Google Drive (data-4, data-5, ui-2, obs-1, truth-2, missed-1/drive) is
  covered by D1: Drive is held out of v1, cannot be picked, and an existing
  Drive vault is read-only and movable, so no Drive write path is left to
  lose text. The underlying Drive defects stay open for whenever Drive
  returns.
- orgvault-6 (the team vault in model context) is deferred to v1.1 by D15.
  The row counts as covered because the deferral itself is pinned: the team
  vault never enters a pack or the vault tools, and its copy makes no agent
  claim.
- 0019 and its pgTAP are on `main` and run in CI; pushing 0019, 0020, and
  0021 to production is a founder gate (PROGRESS, What remains).
- The CI pgTAP job (`.github/workflows/ci.yml`, job `sql`) is the test for
  "the SQL tests never run in CI" (orgvault-13, truth-18).
