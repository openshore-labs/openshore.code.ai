## Decisions

- CTO call: "one owned org per account without an entitlement" means an account may own at most one org that has no live plan. Orgs on a live plan do not count, so a paying team can start a second org and buy for it. Each account then holds at most 25 MiB of free storage.
- CTO call: an org "has a plan" by `isEntitled`'s rule: status active or trialing, and `valid_until` unset or ahead. This is 0015's predicate plus the window. It matches `_shared/entitlement.ts` and the held 0021, and it is the stricter reading for spend.
- CTO call: the byte cap refuses only a note that grows. Revision rows count toward the total but never refuse on their own, because a delete near the cap writes its snapshot before the tombstone, and refusing that would leave no way to make room. The worst case is one snapshot per note above the cap until the weekly purge.
- CTO call: `record_enforcement` was fixed, not just extended. Every column is now qualified. This turns the server-side ladder on for the first time, so the README says to expect `enforcement_actions` rows. A source guard in `supabaseMigrations.test.ts` catches a bare `action` in the newest definition.
- A tombstone is level 2 after a terminate or any abuse report, and level 1 after a warn. Only level 2 is enforced, as the package asked. The reason reads "An earlier account with this email was terminated." rather than claiming an operator acted.
- The email hash lowercases ASCII letters only (`collate "C"` in SQL, `[A-Z]` in TypeScript) and does not trim, so the two sides match in any locale. A Deno test and a pgTAP test pin the same hex value.
- `abuse_reports`: the new check lands `not valid` and is validated only when every row passes. Deduping removes only a queued duplicate. When two reports an operator acted on collide, the index is skipped with a notice rather than deleting evidence.
- Stripe: the function sweeps each known customer's live subscriptions (`status: 'all'`, anything but canceled or incomplete_expired) plus any recorded subscription ids, and cancels them immediately. If Stripe fails, the answer is `billing` (502) and nothing after it runs. `appleNote` is set when the source is Apple or when an `apple_links` row exists.
- CX call (ruling 3): the row sits last in the Your account sheet, below the signed-in card, after the v4-only "Manage the company account". The failure line uses the warning color. The goodbye sheet also closes the account sheet.
- CTO call: the Apple roots check fails only for a build that can sell (`PAY_GATES_ENABLED` true, or `OPENSHORE_STORE_RELEASE=1`). Otherwise it warns, so TestFlight on every push stays green. `APPLE_ROOTS_IN_SECRETS=1` accepts roots kept in function secrets. Only AppleRootCA-G3 is required, because it is the load-bearing root.
- Paywall: when StoreKit gives no price, the line reads "One person, the whole app. See the price in the App Store." The renewal line uses CX's corrected path.
- "Email support" opens `mailto:support@openshore.ai`. On the desktop, that needed `mailto:` added to Electron's window-open handler (`app/electron/main.ts:671`), which is outside this package.
