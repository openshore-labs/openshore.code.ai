# Security

If you find a security problem in OpenShore, please tell us privately at
support@openshore.ai, with "Security" in the subject, rather than in a
public issue. Say what you found, how to reproduce it, and what it affects.

We will answer, keep you posted while we fix it, and credit you when the fix
ships unless you would rather we did not.

Supported: the latest release of the desktop apps and the iPhone app, and
`main`.
